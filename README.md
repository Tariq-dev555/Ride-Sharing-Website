🚗 Ride Sharing Website

   A fully responsive Ride Sharing Web Application UI built using HTML, CSS, and JavaScript.
   This project focuses on modern UI design, responsiveness, and clean user experience.

✨ Features

   📱 Fully responsive design (Mobile, Tablet, Desktop)
   🚗 Ride booking interface UI
   🧭 Clean and modern navigation bar
   🎨 Smooth and modern UI design
   ⚡ Fast and lightweight frontend
   💻 Built with pure HTML & CSS
